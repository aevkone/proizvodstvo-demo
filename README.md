# Система контроля производства — MVP

Веб-сервис для инструментального производства: контроль движения заказов по этапам (план/факт, просрочки, обязательный комментарий при отклонении), уведомления на почту и калькулятор стоимости с ТКП для клиента. Пилот — гражданское направление (без ГОЗ).

## Запуск

Нужен Node.js 22.5+ (используется встроенная SQLite — отдельная СУБД не нужна).

```bash
npm install
npm start
```

Откройте http://localhost:3000. При первом запуске база заполняется демо-данными.

| Логин | Роль | Пароль |
|-------|------|--------|
| `ceo` | Генеральный директор — обзор, только просмотр | `demo123` |
| `prod` | Директор производства — полный доступ, пользователи | `demo123` |
| `tech` | Главный технолог — этапы, маршруты, нормо-часы, справочники | `demo123` |
| `sales` | Начальник коммерческого отдела — новые проекты, согласование, калькулятор | `demo123` |

Сбросить базу к демо-данным (сервер остановить): `npm run seed`. Тесты: `npm test`.

## Настройка

Скопируйте `.env.example` в `.env`. Главное:

- `SMTP_*`, `MAIL_FROM` — почта клиента. Пока SMTP не задан, письма не уходят, а сохраняются в `outbox/` (`.eml` открывается в почтовом клиенте, `.html` — в браузере) и видны на экране «Уведомления».
- `APP_URL` — внешний адрес системы, для ссылки в письмах.
- `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` — по желанию, дублирование уведомлений в группу.

Перед реальной эксплуатацией смените пароли демо-пользователей (Справочники → Пользователи) или создайте базу без демо-проектов.

## Разделы

- **Проекты** — карточки заказов: этап N из M, прогресс, метка «в срок / внимание / просрочка», фильтры и поиск. Карточка проекта: этапы с датами план/факт, ответственные, «Готово сегодня», обязательный комментарий при отклонении, цикл доработки (разборка → подгонка → повторная сборка → повторные испытания), статус согласования с заказчиком.
- **Калькулятор** — материалы + нормо-часы × ставка + прочее, наценка, НДС; ТКП для печати/PDF.
- **Отчёты** — сроки под угрозой, узкие места по этапам, переходы на неделю, сдачи на месяц, просрочки по ответственным.
- **Справочники** — маршруты и этапы, виды работ и ставки, материалы, клиенты, пользователи.
- **Уведомления** — журнал писем и предпросмотр. Проверка каждые 15 минут и сразу после сохранения этапов.

## Устройство

```
src/      сервер: app.js (API), projects.js, status.js (правила статусов), estimates.js,
          notify.js (уведомления), refs.js (справочники), auth.js (вход и роли), seed.js
public/   интерфейс без сборки: app.js (роутинг), lib.js, views/*.js, styles.css
test/     node:test — статусы, API, права, калькулятор, уведомления, справочники
data/     файл базы (создаётся автоматически)
```

Резервная копия — файл `data/app.db` (остановить сервер или копировать вместе с `-wal`).

## Развёртывание на сервере (вариант)

Любой VPS с Node.js: `npm ci --omit=dev`, `.env` с SMTP и `APP_URL`, запуск через systemd или pm2 (`pm2 start npm --name proizvodstvo -- start`), перед ним nginx с HTTPS. Хостинг и домен — по согласованию с клиентом.
