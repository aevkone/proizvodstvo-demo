# Design — «Диспетчерская доска цеха»

Режим: Operate. Метафора: эмалированная диспетчерская доска мастера — заказы как бирки, статус как цветной магнит, маршрут как полоса этапов. Токены — `public/styles.css` (`:root`).

## Цвет (Restrained + семантика статусов)
- Эмаль доски `--board #f3f4f1`, бумага бирок `--paper #fff`, графитовая рама `--frame #1f2428` (сайдбар, табло, главные кнопки).
- Текст `--ink #16191c` / `--ink-2 #454c52` / `--ink-3 #646b71` (все ≥4.5:1 на белом).
- Магниты: в срок `--ok #2f8f5b`, внимание `--warn #e0a100`, просрочка `--bad #d33a2c`, текущий этап — графит. Цвет только для статуса и действия, не для декора.
- Просрочка в полосе маршрута — красная штриховка (как разметка опасной зоны в цеху): это смысл, а не украшение.

## Типографика
- Golos Text — весь интерфейс (400/500/600/700), фиксированная rem-шкала: 26 / 17 / 15 / 13.5 / 12.5.
- JetBrains Mono — только данные: коды заказов, даты, суммы, обратный отсчёт. Не как «технический костюм».

## Компоненты
- **Бирка-код** `.code-tag` — моно, рамка, «люверс» слева.
- **Магнит** `.magnet` / бейдж статуса `.badge` — круг с нижней тенью, как физический магнит.
- **Полоса маршрута** `.route` — сигнатурный элемент: сегмент ∝ длительности этапа; выполнен — серый, с опозданием — охра, текущий — графит/жёлтый, просрочен — штриховка, доработка — жёлтая обводка. Одна и та же на доске, в карточке, отчётах, форме нового проекта и на экране входа.
- **Табло переходов** `.departures` — графитовая панель с моноширинным отсчётом (−2 дн / сегодня / +3 дн), как вокзальное табло.
- Кнопки: primary — графит; secondary — белые с тонкой рамкой; ghost — без фона. Высота 38 / 30 px. Состояния hover, active, focus-visible, disabled, busy.
- Закреплённая панель сохранения со счётчиком несохранённых этапов; предупреждение при уходе со страницы.
- Иконки — собственный набор `public/icons.js`, 24×24, stroke 1.75.

## Движение
150–250 мс, ease-out `cubic-bezier(.16,1,.3,1)`. Единственный авторский момент — «защёлкивание» магнита при закрытии этапа (scale .7→1). `prefers-reduced-motion` отключает анимации.

## Адаптив
≥1180 — доска + табло справа; <1180 — табло над доской; <860 — рама становится верхней панелью с иконками, таблица этапов прокручивается внутри карточки, табло ограничено 4 строками.
